## Как настроить форму RSVP

Форма подтверждения — это Google Forms, уже подключена. Ответы гостей приходят на почту, привязанную к этой Google-форме. Если нужно изменить вопросы — откройте форму в Google Forms и редактируйте.

## Как запустить локально

```bash
cd /Users/pasha/wedding-site
npm install   # установить зависимости (один раз)
npm start     # запустить сервер и открыть браузер
```

Или в режиме разработки (без открытия браузера):

```bash
npm run dev
```

Сайт будет доступен на http://localhost:3000

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (https://github.com/new)
2. Назовите его, например, `wedding` или `katya-pasha-wedding`
3. В терминале выполните команды (замените ВАШ_ЛОГИН и НАЗВАНИЕ_РЕПО):

```bash
cd /Users/pasha/wedding-site
git add .
git commit -m "Первый коммит — свадебный лендинг"
git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПО.git
git push -u origin main
```

4. Зайдите в репозиторий на GitHub → Settings → Pages
5. В разделе «Branch» выберите `main` и нажмите Save
6. Через 1-2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`

## Как редактировать содержимое

Все изменения делаются в файле `index.html`:

- **Имена / дата / время / место** — секция `<section id="hero">`
- **Расписание** — секция `<section id="schedule">`
- **Формат вечера** — секция `<section id="format">`
- **Текст про открытый микрофон** — секция `<section id="open-mic">`

Просто откройте файл в любом текстовом редакторе (Блокнот, TextEdit и т.п.), найдите нужный текст и замените его.
